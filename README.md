# Hit Feel Fight Demo

用最简单几何图形（圆头 + 胶囊身体）做的格斗打击感 Demo。  
落实笔记《用最简单图形做出打击感》要点：蓄力→出拳→命中→击退→回收、攻受同步 hitstop、命中特效、镜头震动、受击闪白/挤压、地面滑痕、血条与简单 AI。可开关特效验证「关特效因果仍成立」。

## 试玩

部署后打开 Worker / Pages URL，或本地：

```bash
npx wrangler dev
# 或直接用浏览器打开 public/index.html
```

## 操作

| 动作 | 键盘 | 触屏 |
|------|------|------|
| 左右移动 | A / D 或 ← → | ◀ 左 / 右 ▶ |
| 轻拳 | J | 轻拳 |
| 重拳 | K | 重拳 |
| 跳 / 空中闪 | W / 空格 | 跳/闪 |
| 格挡 | S / L | （键盘） |
| 开关特效 | F | 右上角按钮 |

## 打击感清单

- 完整动作链：蓄力 → 出拳 → 命中 → 击退 → 回收
- 攻受同步 hitstop（轻/重不同时长；卡帧时低速续动，不完全定死）
- 命中点冲击圈 + 火花/碎片；卡帧结束主特效散尽
- 镜头震动 + 轻微推拉，按攻击阶段绑定；连击克制
- 受击闪白、挤压拉伸、击退与地面滑痕
- 血条 + 会走位/出拳/格挡的 AI
- 特效开关、可选 WebAudio 打击音

## 技术

单文件 `public/index.html`：Canvas + 原生 JS，无外部依赖。Cloudflare Workers Static Assets 部署。
